## Quick Setup Commands (WP-CLI)

If you have WP-CLI access, run these:

```bash
# Create main categories
wp woocommerce product_cat create --name="Access Control" --slug="access-control"
wp woocommerce product_cat create --name="CCTV Surveillance" --slug="cctv-surveillance"
wp woocommerce product_cat create --name="Conference System" --slug="conference-system"
wp woocommerce product_cat create --name="PA System" --slug="pa-system"
wp woocommerce product_cat create --name="Walkie Talkie" --slug="walkie-talkie"
wp woocommerce product_cat create --name="Networking" --slug="networking"
wp woocommerce product_cat create --name="PABX & IP Phone" --slug="pabx-ip-phone"
wp woocommerce product_cat create --name="Security Solutions" --slug="security-solutions"
wp woocommerce product_cat create --name="Office Equipment" --slug="office-equipment"

# Create pages
wp post create --post_type=page --post_title="About Us" --post_status=publish
wp post create --post_type=page --post_title="Contact Us" --post_status=publish
wp post create --post_type=page --post_title="Brands" --post_status=publish
wp post create --post_type=page --post_title="FAQs" --post_status=publish
wp post create --post_type=page --post_title="Track Order" --post_status=publish
```
